# PEP 8 na Prática: Refatoração e Boas Práticas em Python

Trabalho final da disciplina **Boas Práticas de Programação** — Análise e 
Desenvolvimento de Sistemas, IFMG Campus Ouro Preto (2026.1).

Este repositório reúne o material produzido pelo grupo sobre a **PEP 8**, 
o guia de estilo oficial para código Python, incluindo:

- 📊 Slides didáticos explicando os principais pontos da PEP 8
- 🎥 Vídeo curto com dicas práticas
- 🐍 Código Python original (antes) e refatorado (depois)
- 📄 Relatório explicando as melhorias aplicadas

## Objetivo
Demonstrar que programar bem vai além de fazer o código funcionar: 
envolve legibilidade, padronização e manutenibilidade.

## Estrutura do repositório
- `slides/` – apresentação da mini-aula
- `video/` – link ou arquivo do vídeo
- `codigo_original.py`
- `codigo_refatorado.py`
- `relatorio_melhorias.pdf`
